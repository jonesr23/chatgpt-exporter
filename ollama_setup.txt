Ollama setup for linux:

1. Download Ollama from https://ollama.com/download
  - From terminal Run:
    curl -fsSL https://ollama.com/install.sh | sh
2. Start Ollama
  - In terminal run:
  ollama serve

3. Download model (for this project using qwen3-vl)
  - In terminal run:
    ollama pull qwen3-vl
